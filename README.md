# MedEngs OfficeAgent for Dental

Account-based AI office agent for dental clinics: forms, PDFs, branded patient links, clinic cloud files, patient admin memory, task/follow-up flags, and compliance-first auditability.

## Start
```bash
npm install
npm run dev
```

## Verify
```bash
npm run typecheck
npm run build
```
